Règles de confidentialité de TPhrase

Mise à jour le 26 septembre 2026

En résumé : TPhrase ne collecte aucune donnée. Vos phrases et vos textes restent dans votre navigateur Chrome, sur votre ordinateur. Rien n'est envoyé au développeur de l'extension.

Ce que TPhrase enregistre

  • Vos listes, rubriques et phrases, vos favoris et le nombre d'utilisations de chaque phrase.
  • Vos réglages d'apparence (couleurs, police, taille).
  • Le texte en cours dans l'onglet Rédiger, pour le retrouver à la réouverture.

Ces données sont enregistrées dans le stockage local de Chrome, sur votre ordinateur. Elles ne sont ni envoyées, ni partagées, ni vendues. Elles sont effacées si vous désinstallez l'extension. Les sauvegardes JSON ou CSV que vous exportez sont des fichiers enregistrés sur votre ordinateur.

Onglet Rédiger et intelligence artificielle

La reformulation utilise l'IA intégrée à Google Chrome (Gemini Nano, via la Prompt API). Le modèle fonctionne sur votre ordinateur : le texte à reformuler n'est pas envoyé sur Internet. Chrome télécharge le modèle une seule fois, à la première utilisation.

Les résultats de l'IA peuvent contenir des erreurs : relisez-les avant de les utiliser. L'usage de l'IA est soumis au règlement de Google sur les utilisations interdites de l'IA générative.

Dictée vocale

Le bouton micro utilise la reconnaissance vocale de Chrome. Selon votre version de Chrome, votre voix peut être envoyée aux serveurs de Google pour être transformée en texte, selon les règles de confidentialité de Google. TPhrase ne reçoit que le texte obtenu et ne l'envoie nulle part. La dictée est facultative : si vous tapez votre texte au clavier, rien ne quitte votre ordinateur.

Permissions

  • sidePanel : afficher TPhrase dans le panneau latéral de Chrome, si vous choisissez de l'y ancrer.

TPhrase ne lit pas les pages web que vous visitez et n'a accès à aucun site.

Contact

Pour toute question, utilisez l'onglet Assistance de la fiche TPhrase sur le Chrome Web Store.
