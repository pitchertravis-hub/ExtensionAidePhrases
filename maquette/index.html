Technologie

La meilleure option sans rien installer

HTML, CSS et JavaScript modernes, sans bibliothèque de plus. L'extension ne tourne que dans Chrome, qui sait déjà faire tout ce dont elle a besoin : fenêtres de dialogue, menus, modules JavaScript, variables CSS. On écrit les fichiers, on recharge l'extension, on zippe le dossier et on l'envoie sur le Chrome Web Store, exactement comme aujourd'hui.

Pas de Node, pas de npm, pas d'étape de construction. La seule bibliothèque gardée est Sortable.min.js, déjà dans le dossier.

OptionInstallationVerdict
JavaScript natif en modules retenuAucuneTout ce qu'il faut est intégré à Chrome. Code découpé en petits fichiers, zéro dépendance nouvelle.
Preact + htm (un fichier .js copié dans lib/)AucunePossible et léger (~5 Ko), mais ajoute une façon d'écrire à apprendre pour trois petites vues.
Alpine.js, petite-vueAucunebloqué Leur version standard exécute du code à partir de texte, ce que Chrome interdit dans les extensions Manifest V3.
React, Vue, WXT, ViteNode + npmécarté Demande d'installer Node et de construire l'extension avant chaque essai.

Ce que Chrome fournit déjà

  • <dialog>Fenêtres « Renommer », « Supprimer ? », texte d'intro ID. Remplace prompt, confirm et alert.
  • Attribut popoverMenus « ⋯ » et Réglages : se ferment seuls au clic dehors ou avec Échap.
  • <script type="module">Découpe le code en fichiers avec import / export.
  • Variables CSSUne palette claire et une sombre, basculées par un seul attribut.
  • Icônes SVG inlineDans popup.html, plus de lien vers Font Awesome sur Internet.
  • Police ManropeUn fichier .woff2 placé dans fonts/. Sinon, la police système Segoe UI.

Plan

Déroulé en six étapes

Chaque étape se teste en rechargeant l'extension dans chrome://extensions (mode développeur, « Charger l'extension non empaquetée »). La v2.5 reste sur main jusqu'à la fin.

ÉTAPE 1

Style

  • Écrire tokens.css, base.css, views.css d'après la maquette.
  • Garder 150 / 765 / 300 px + 5 px de marge.
  • Ajouter la police dans fonts/.
css/ · fonts/
ÉTAPE 2

Structure HTML

  • Refaire popup.html : en-tête, contenu, pied par vue.
  • Icônes SVG, suppression de Font Awesome.
  • Feuilles de style dans <head>, balise invalide retirée.
popup.html
ÉTAPE 3

Découpage du code

  • Passer en type="module", créer store.js et core/.
  • Même comportement qu'avant, mêmes clés localStorage.
js/
ÉTAPE 4

Les trois vues

  • Rubriques : compteur, « ⋯ », micro, filet doré.
  • Phrases : numéro-poignée, Copier / Copié, corbeille.
  • Navigation ID : parcours 1-2-3, carte résultat.
js/views/
ÉTAPE 5

Dialogues et annulation

  • <dialog> à la place de prompt/confirm/alert.
  • Menus en popover. Barre « Annuler » après suppression.
js/ui/
ÉTAPE 6

Recette et publication

  • Charger par-dessus la v2.5 : les listes doivent apparaître.
  • Tester clair/sombre, voix, import d'un ancien export.
  • Version 3.0, zip, envoi sur le Web Store.
