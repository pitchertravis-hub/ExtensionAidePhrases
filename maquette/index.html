Plan

Déroulé en cinq étapes

Chaque étape laisse l'extension utilisable et fait l'objet d'un commit séparé, testable en rechargeant l'extension dans chrome://extensions.

Étape 1

Fondations CSS

  • Réécrire styles.css autour des variables (clair et sombre).
  • Police système Segoe UI, taille 13 px, échelle 11 / 12 / 13 / 14 / 17.
  • Garder #interface1/2/3 à 150 / 765 / 300 px + 5 px de marge.
  • Charger la feuille de style dans <head> (évite le flash sans style).
styles.css · popup.html
Étape 2

Structure HTML et icônes

  • En-tête / contenu / pied pour chaque vue, comme la maquette.
  • Remplacer Font Awesome par un sprite SVG inline.
  • Supprimer la balise invalide <class="menu-btn" id="settingsBtn"> (id en double).
  • Garder les mêmes id utilisés par les scripts quand c'est possible.
popup.html · icons/
Étape 3

Composants

  • Rubrique : compteur de phrases + bouton « ⋯ ».
  • Phrase : poignée, Copier avec retour visuel, corbeille.

Compatibilité

Ce qui ne bouge pas

Les données restent dans localStorage avec les mêmes clés. Rien à migrer, les anciens exports JSON s'importent toujours.

  • listes : listes, rubriques, phrases
  • selectedList : dernière liste ouverte
  • theme : clair ou sombre
  • customIntroText : phrase d'introduction ID
  • lastExportDate : date de la dernière sauvegarde
  • Tailles des fenêtres : 160 / 775 / 310 px
